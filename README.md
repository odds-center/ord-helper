# ORD Helper (원랜디 도우미)

워크래프트3 리포지드 유즈맵 **원피스 랜덤 디펜스(원랜디)** 조합 도우미입니다.
내 유닛으로 지금 만들 수 있는 조합, 모자란 재료, 목표까지 남은 것을 한눈에 보여 줍니다.

## 받기

[Releases](../../releases/latest)에서 받으세요.

- **Windows**: `ORD-Helper-Setup-<버전>.exe` 실행 → 바탕화면 **원랜디 도우미**
  - 처음 실행할 때 "Windows의 PC 보호"가 뜨면 **추가 정보 → 실행**
  - 한 번 설치하면 새 버전이 나올 때 프로그램 위쪽에 **업데이트** 버튼이 뜹니다 (누르면 알아서 설치하고 다시 켜짐)
- **맥** (Apple Silicon): `ORD-Helper-<버전>-mac.dmg` → **원랜디 도우미**를 Applications로 끌어다 놓기
  - "손상되어 열 수 없다"고 나오면 dmg 안의 **열리지 않을 때**를 오른쪽 클릭 → 열기
  - 맥은 게임 실시간 연동 없이 수동 입력·세이브 기능만

## 알아 둘 것

- 게임 중 내 유닛은 게임 메모리를 **읽기만** 해서 셉니다 (쓰기·주입·후킹 없음, Windows · 게임 3.0.1.24371 기준).
- 조합식·유닛 정보는 [TMO.GG 조합도우미](https://tmo.gg/g/ord/build-helper)와 위키를 바탕으로 했습니다. 데이터의 권리는 TMO.GG와 위키 편집자에게 있습니다.
- 블리자드·TMO.GG와 관계없는 개인 제작 프로그램입니다.
